# STMPCK beta website

This repository is the website for STMPCK (pronounced “stimpack”), an offline collection of small games for cognitive and sensory play. It’s designed primarily for neurodivergent people and welcomes everyone.

STMPCK is currently in beta and looking for testers. Try a few games, adjust the visual intensity, or see how it feels to leave and pick up where you stopped. We’d like to hear what felt good, what got in your way, and what you’d change.

- [Download the Android beta APK](https://raw.githubusercontent.com/cjtrowbridge/stmpck-builds/main/latest.apk). Open the downloaded file on your phone and follow Android’s installation prompts.
- [Share beta feedback on GitHub](https://github.com/cjtrowbridge/stmpck.com/issues/new). If you’re reporting a bug, include your phone model, Android version, and what you were doing when it happened. GitHub issues are public.

Open `index.html` in a browser to preview the site. The page uses local gameplay stills and needs no build step. See [LICENSE](LICENSE) for licensing terms.
